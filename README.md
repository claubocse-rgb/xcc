# XCC · Echipa

Aplicație simplă pentru grupul nostru la **Xtreme Character Challenge** (4M România): echipament individual și de echipă, transport cu mașinile, echipe și aprobarea conturilor.

- Site: https://claubocse-rgb.github.io/xcc/
- Date și conturi: Supabase (proiectul `xcc-4m`)
- `schema.sql` – tabelele, regulile de securitate și lista oficială de echipament (se rulează o singură dată în SQL editor)

Conturile noi intră „în așteptare” până le aprobă organizatorul din pagina Admin.
